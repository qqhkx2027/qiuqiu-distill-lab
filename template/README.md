# {对象名}蒸馏 Skill —— 模板说明

## 这个目录是什么

这是一个可复制的模板。想蒸馏一个新的名人、书、或文章时：

1. 复制本目录为新名称：`distilled/名字/`
2. 打开 SKILL.md，按注释替换内容
3. 把原材料放进 source/ 或 references/
4. 更新上一级 README 的清单

## 三种蒸馏方式，选一种或组合

| 方式 | 适合 | 输出 |
| --- | --- | --- |
| 人物心智蒸馏（女娲式） | 想借鉴某个人的思维方式 | 五层认知：心智模型/决策启发式/表达DNA/反模式底线/诚实边界 |
| 课程化蒸馏 | 想体系化学习一本书/一门课 | 6-8 个模块，每个有目标/练习/检查 |
| book-to-skill 式 | 想省 token、当外挂大脑 | 核心索引 + 章节按需加载 |

## 注意事项

- 不复制原文；只提炼方法框架。
- 标注来源和引用边界。
- 名人蒸馏不制造“数字分身”，不冒充本人的权威性。
