# book-to-skill 式蒸馏：外挂大脑（省 Token）

> 蒸馏方法：仿 book-to-skill：运行时只加载核心小文件，章节按需取用。
> 目标：把整篇原文压缩成可检索的“外挂大脑”，省 24–51 倍 token。

## 核心索引（constants 小文件，约 2KB）

- 触发条件：用户提到“想改变但回到原状 / 我不知道自己想要什么 / 拖延”。
- 主流程：先看行为 → 找隐藏目标 → 识别旧身份 → 走一天协议 → 产出六项。
- 六项：反愿景 | 愿景 | 一年镜头 | 一月项目 | 每日动作 | 约束。
- 常用清单：
  - 表面目标（想要自律） vs 隐藏目标（害怕被评价）
  - 8 步身份循环
  - 三阶段：失谐 → 不确定 → 发现
  - 24 小时协议：早反愿景 / 午打断 / 晚合成
- 边界：非心理诊断；不能归为身份问题；不生成数字分身。
