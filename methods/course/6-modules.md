# 课程化蒸馏结果：一天的 6 个模块

> 蒸馏方法：把长文按“模块 → 目标 → 练习 → 检查”重排（仿仓颉/视频转 skill 思路）

## 课程说明

- 阅读时长：跟随原文约为 1 天
- 模块分配：上午 2，下午 3，晚上 1
- 配套：可搭配原文视频版逐段核对

### 模块 1：为什么新年目标总失败
- 目标：看到“只改行动”与“改身份”的差异。
- 关键内容：成功两要素——改行动（次要） vs 改“我是谁”（主要）。
- 练习：写自己近一年一条“定了目标却放弃”的事，标出属于哪种要素。
- 检验：能用一句话解释为什么练肌肉的人不必强迫健康饮食。

### 模块 2：识别行为背后的隐藏目标
- 目标：把拖延、不敢离开旧工作，解释成保护机制。
- 关键内容：所有行为都有目标；表面目标 vs 隐藏目标。
- 练习：问自己“我现在的行为在保护我避免什么？”
- 检验：能列出自己的“表面目标 / 实际目标”对照。

### 模块 3：身份的循环（8 步）
- 目标：理解身份如何自我维持。
- 关键内容：目标→感知→信息→行动→反馈→自动化→“我就是”→维护身份。
- 练习：画自己的 8 步循环图。
- 检验：能把“我就是不擅长 X”改写成循环图。

### 模块 4：改变的三个阶段
- 目标：预测改变会受的阻力。
- 关键内容：失谐（Dissonance）→ 不确定（Uncertainty）→ 发现（Discovery）。
- 练习：判断自己当前处在哪阶段。
- 检验：能解释为什么发现通常在不确定之后。

### 模块 5：一天的完整协议
- 目标：执行反愿景 + 停止自动模式 + 晚间合成。
- 上午：反愿景（5/10 年的周二）+ 愿景 MVP。
- 下午：6 个定时打断问题。
- 晚上：写出一句反愿景、一句愿景、一年镜头 / 一月项目 / 每日动作。
- 练习：按流程执行一轮。
- 检验：能写成六项输出卡片。

### 模块 6：把结果变成游戏
- 目标：把输出结构化为可维护的生活 OS。
- 内容：愿景 / 反愿景 / 一年=使命 / 一月=Boss / 每日=任务 / 约束=规则。
- 练习：把六项画成六层圆环。
- 检验：能用六项对应“如果我要转行”的一条可行路径。

## 交付标准

- 学完能用一张 A4 写下六项，并指得出“哪项在阻碍我”。
